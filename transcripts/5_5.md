# 5.5 Using the Candidates Test to Determine Absolute (Global) Extrema

## A short list
**On screen:** A curve on a closed interval [a, b]. Dots appear at the two endpoints and at the two critical points inside. Each dot gets a height label; the highest and lowest are circled.
> On a closed interval, a continuous function has a highest value and a lowest value. Where can they be? [pause]
> Inside the interval, a highest or lowest point has to be a critical point. Otherwise it could go a little higher or lower. [pause]
> Or it can sit at an endpoint, where the interval just stops. [pause]
> So there's a short list of candidates: the critical points and the endpoints. [long pause]

## Title
**On screen:** (No narration: the card shows with the intro music.) Title card: "Topic 5.5 · Using the Candidates Test to determine absolute (global) extrema." Unit 5 · Analytical Applications of Differentiation.

## The test
**On screen:** Three steps: 1. Find the critical points in (a, b). 2. Evaluate f at each one and at both endpoints. 3. The largest is the absolute max; the smallest is the absolute min.
> Here's the Candidates Test. Find the critical points inside the interval. [pause]
> Evaluate f at each of them, and at both endpoints. [pause]
> The biggest value is the absolute maximum. The smallest is the absolute minimum. [long pause]

## Don't skip the endpoints
**On screen:** The graph of y = x³ − 3x on [0, 3]. The only critical point, x = 1, gives −2. The endpoint x = 3 gives 18, far higher.
> The endpoints matter. On zero to three, x cubed minus three x has one critical point, at x equals one. [pause]
> f of one is negative two. That's the minimum. But the maximum isn't at a critical point at all. [pause]
> It's at the endpoint: f of three is eighteen. [long pause]

## Inputs and outputs
**On screen:** The graph of y = x³ − 3x on [0, 3] again, with the high point (3, 18) marked. A dashed line runs left to the y-axis, labeled "the maximum: 18 (an output, a value of f)". Another runs down to the x-axis, labeled "where: x = 3 (an input)". Then two questions side by side: "What is the absolute maximum?" with answer "18", and "At what x does it occur?" with answer "x = 3".
> Keep inputs and outputs straight. [pause]
> The maximum is an output: a value of f. Here, the absolute maximum is eighteen. [pause]
> Where it happens is an input: x equals three. [pause]
> So say both, each in its place: the absolute maximum is eighteen, at x equals three. [pause]
> And read the question carefully. "What is the absolute maximum?" wants eighteen. "At what x does it occur?" wants three. Mixing those up is the most common way to lose this point. [long pause]

## A parabola on an interval
**On screen:** The problem on top. Board: f′(x) = 2x − 4; 2x − 4 = 0, so x = 2; candidates: f(0) = 0; f(2) = 4 − 8 = −4; f(5) = 25 − 20 = 5; absolute max: 5 (output), at x = 5 (input); absolute min: −4 (output), at x = 2 (input).
> Find the absolute extrema of x squared minus four x on zero to five. Give each value and where it happens. [try it]
> f prime is two x minus four. [pause]
> Set it equal to zero: two x minus four equals zero, so x equals two. That's inside the interval. [pause]
> Now the candidates: the critical point and both endpoints. f of zero is zero.
> f of two: four minus eight, negative four.
> f of five: twenty-five minus twenty, five. [pause]
> The biggest output is five. That's the absolute maximum, and it happens at the input x equals five.
> The smallest output is negative four: the absolute minimum, at x equals two. [long pause]

## Close
**On screen:** A table with columns "x" and "f(x)": endpoints and critical points in the rows, the largest and smallest values highlighted.
> Make the table, fill it in, and pick the biggest and smallest. On the AP exam, the table is your justification. [long pause]

# Worked examples

## Example 1: Just the value
**On screen:** "Find the absolute maximum value of f(x) = x³ − 3x + 1 on [0, 3]." Board: f′(x) = 3x² − 3; 3x² − 3 = 0; x² = 1; x = ±1, and only x = 1 is in [0, 3]; f(0) = 1; f(1) = 1 − 3 + 1 = −1; f(3) = 27 − 9 + 1 = 19; absolute maximum value: 19.
> Find the absolute maximum value of x cubed minus three x plus one on zero to three. [pause]
> f prime is three x squared minus three. [pause]
> Set it equal to zero: three x squared equals three, so x squared equals one, and x is plus or minus one.
> Negative one isn't in the interval, so the only critical point is x equals one. [pause]
> Candidates: f of zero is one. f of one: one minus three plus one, negative one. f of three: twenty-seven minus nine plus one, nineteen. [pause]
> The question asks for the maximum value, an output. So the answer is nineteen. It happens at x equals three, but the value is what was asked. [long pause]

## Example 2: Just the location
**On screen:** "At what value of x does f(x) = x − 2ln x attain its absolute minimum on [1, e²]?" Board: f′(x) = 1 − 2/x; 1 − 2/x = 0; 2/x = 1, so x = 2; f(1) = 1; f(2) = 2 − 2ln 2 ≈ 0.614; f(e²) = e² − 4 ≈ 3.389; smallest output at x = 2; answer: x = 2.
> At what value of x does x minus two natural log x reach its absolute minimum on one to e squared? [pause]
> f prime is one minus two over x. [pause]
> Set it equal to zero: two over x equals one, so x equals two.
> Candidates: f of one is one. f of two is two minus two ln two, about point six one. [pause]
> f of e squared is e squared minus two times two: e squared minus four, about three point three nine.
> The smallest output is at x equals two. The question asks where, an input. So the answer is x equals two, not point six one. [long pause]

## Example 3: Both
**On screen:** "Find the absolute maximum and minimum values of f(x) = sin x + cos x on [0, π], and where each occurs." Board: f′(x) = cos x − sin x; cos x − sin x = 0; cos x = sin x, so x = π/4; f(0) = 0 + 1 = 1; f(π/4) = √2/2 + √2/2 = √2; f(π) = 0 + (−1) = −1; absolute max √2 at x = π/4; absolute min −1 at x = π.
> Find the absolute maximum and minimum values of sine x plus cosine x on zero to pi, and where each occurs. [pause]
> f prime is cosine x minus sine x. [pause]
> Set it equal to zero: cosine x equals sine x. Between zero and pi, that happens only at pi over four.
> Candidates: f of zero is zero plus one, one. f of pi over four is root two over two plus root two over two: root two. f of pi is zero plus negative one, negative one. [pause]
> The absolute maximum is root two, at x equals pi over four. The absolute minimum is negative one, at x equals pi. [long pause]
