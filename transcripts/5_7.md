# 5.7 Using the Second Derivative Test to Determine Extrema

## Flat on top, flat on the bottom
**On screen:** Two graphs, each with a horizontal tangent at a marked point. The first is a hill (concave down) with its flat spot at the top; the second is a bowl (concave up) with its flat spot at the bottom.
> Both of these graphs have a horizontal tangent at the marked point. [pause]
> The first one bends downward, like a hill. A hill with a flat spot has to be flat at the top: a maximum. [pause]
> The second bends upward, like a bowl. A bowl with a flat spot is flat at the bottom: a minimum. [long pause]

## Title
**On screen:** (No narration: the card shows with the intro music.) Title card: "Topic 5.7 · Using the Second Derivative Test to determine extrema." Unit 5 · Analytical Applications of Differentiation.

## The test
**On screen:** "Suppose f′(c) = 0." Then three lines: "f″(c) < 0: relative maximum." "f″(c) > 0: relative minimum." "f″(c) = 0: no conclusion."
> Here's the Second Derivative Test. Start with a critical point where f prime of c is zero. [pause]
> If f double prime of c is negative, the graph is concave down there: a relative maximum. [pause]
> If f double prime of c is positive, concave up: a relative minimum. [pause]
> And if f double prime of c is zero, the test says nothing. [long pause]

## Using the test
**On screen:** The problem on top. Board: f′(x) = 6x² − 6; 6x² − 6 = 0, x² = 1, x = ±1; f″(x) = 12x; f″(−1) = −12 < 0: concave down, relative max; f″(1) = 12 > 0: concave up, relative min.
> Classify the critical points of two x cubed minus six x. [try it]
> f prime is six x squared minus six. [pause]
> Set it equal to zero: six x squared equals six, so x squared equals one, and x is plus or minus one.
> Differentiate again: f double prime is twelve x. [pause]
> At negative one: twelve times negative one, negative twelve. Negative, so concave down: a relative maximum.
> At one: twelve. Positive, so concave up: a relative minimum. [long pause]

## When the test is silent
**On screen:** Three small graphs: y = x⁴ (a minimum), y = −x⁴ (a maximum), y = x³ (neither). All three have f′(0) = 0 and f″(0) = 0.
> Zero tells you nothing. These three functions all have f prime and f double prime equal to zero at the origin. [pause]
> The first has a minimum there, the second a maximum, and the third neither. [pause]
> When the second derivative test is silent, go back to the first derivative test. [long pause]

## Which test?
**On screen:** Two columns. "Second Derivative Test": quick: plug c into f″; no number line; only where f′(c) = 0; silent when f″(c) = 0. "First Derivative Test": always gives an answer; works where f′ is undefined (corners, cusps); needs a number line; gives the increasing and decreasing intervals too. Beneath: "f″ easy and f′(c) = 0: try the second. Otherwise, or if f″(c) = 0: use the first."
> So which test should you use? It's a choice, and when both work, both give the right answer. [pause]
> The second derivative test is quick: find f double prime, plug in the critical point, read the sign. No number line. It's a good choice when f double prime is easy to find. [pause]
> But it only works where f prime is zero, and it's silent when f double prime is zero. [pause]
> The first derivative test always gives an answer, even at corners and cusps where f prime is undefined. It's the better choice when f double prime is messy, or when you need the increasing and decreasing intervals anyway. [pause]
> A good habit: if f double prime is easy, try the second derivative test. If it comes out zero, or f prime is undefined, go back to the first. [long pause]

## One critical point
**On screen:** A curve on (0, ∞) with a single valley. A dot at the bottom is labeled "only critical point: relative min, so absolute min."
> One more useful fact. Suppose a continuous function has only one critical point on an interval, and it's a relative minimum. [pause]
> Then it's the absolute minimum on that interval. To come back down below it, the graph would need another critical point. [long pause]

## Close
**On screen:** "f′(c) = 0 and f″(c) < 0: max. f′(c) = 0 and f″(c) > 0: min. f″(c) = 0: use the first derivative test."
> At a horizontal tangent, concave down is a max and concave up is a min. When f double prime is zero, use the first derivative test. [long pause]

# Worked examples

## Example 1: A cubic
**On screen:** "Use the Second Derivative Test to classify the critical points of f(x) = x³ − 3x² + 4." Board: f′(x) = 3x² − 6x; = 3x(x − 2); 3x = 0 or x − 2 = 0, so x = 0 or x = 2; f″(x) = 6x − 6; f″(0) = −6 < 0: concave down, relative max at x = 0; f″(2) = 12 − 6 = 6 > 0: concave up, relative min at x = 2.
> Use the Second Derivative Test to classify the critical points of x cubed minus three x squared plus four. [pause]
> f prime is three x squared minus six x. [pause]
> Factor out three x: three x, times x minus two. Set each factor equal to zero: x equals zero or x equals two.
> f double prime is six x minus six. [pause]
> At zero, that's negative six. Negative: concave down, so a relative maximum.
> At two, it's twelve minus six, positive six: concave up, so a relative minimum. [long pause]

## Example 2: When the test fails
**On screen:** "Classify the critical point of f(x) = x⁴." Board: f′(x) = 4x³; 4x³ = 0, so x = 0; f″(x) = 12x²; f″(0) = 0: inconclusive; switch to the first derivative test; f′(−1) = −4 < 0; f′(1) = 4 > 0; − to +: relative min at x = 0. On the right, a number line for f′ with 0 marked; signs −, + appear as tested, "dec, inc" beneath, then "min" over 0.
> Classify the critical point of x to the fourth. [pause]
> f prime is four x cubed. Set it equal to zero: x cubed is zero, so x is zero.
> f double prime is twelve x squared, and at zero that's zero. The second derivative test is inconclusive. [pause]
> So switch to the first derivative test. Put zero on a number line for f prime, and test each side. f prime of negative one is negative four. Negative.
> f prime of one is four. Positive. [pause]
> f prime changes from negative to positive at zero: a relative minimum. [long pause]

## Example 3: The only critical point
**On screen:** "Find the absolute minimum value of f(x) = x + 4/x on (0, ∞). Justify." Board: f′(x) = 1 − 4/x²; 1 − 4/x² = 0, 4/x² = 1, x² = 4, x = ±2; only x = 2 is in (0, ∞); f″(x) = 8/x³; f″(2) = 8/8 = 1 > 0: relative min; the only critical point on (0, ∞), so the absolute minimum; f(2) = 2 + 2 = 4.
> Find the absolute minimum value of x plus four over x, for positive x. Justify your answer. [pause]
> f prime is one minus four over x squared. [pause]
> Set it equal to zero: four over x squared equals one, so x squared equals four, and x is plus or minus two. Only two is positive.
> f double prime: the derivative of negative four x to the negative two is eight x to the negative three, eight over x cubed. [pause]
> At two, that's eight over eight, one. Positive, so a relative minimum.
> It's the only critical point on the interval, so it's the absolute minimum. [pause]
> The question asks for the value: f of two is two plus two, four. [long pause]
