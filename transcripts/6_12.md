# 6.12 Integrating Using Linear Partial Fractions

## Adding fractions, backward
**On screen:** Forward: "2/(x − 1) + 3/(x + 2) = (2(x + 2) + 3(x − 1))/((x − 1)(x + 2)) = (5x + 1)/((x − 1)(x + 2))". Then an arrow back from the right side to the left, labeled "partial fractions". At the bottom: "∫ A/(x − r) dx = A ln|x − r| + C".
> In algebra, you added fractions such as two over x minus one plus three over x plus two by finding a common denominator. You get five x plus one over the product. [pause]
> Partial fractions runs that backward: it splits one fraction into simpler pieces. [pause]
> And each simple piece, a number over a linear factor, integrates to a natural log. [long pause]

## The method
**On screen:** The problem: "Find ∫ 1/(x² − 1) dx." In the corner, the split rule: "p(x)/((x − r)(x − s)) = A/(x − r) + B/(x − s)". Board, one line at a time: x² − 1 = (x − 1)(x + 1); 1/((x − 1)(x + 1)) = A/(x − 1) + B/(x + 1); "Multiply both sides by (x − 1)(x + 1)."; 1 = A(x + 1) + B(x − 1); "Let x = 1:" 1 = A(1 + 1) + B(1 − 1); 1 = 2A, so A = ½; "Let x = −1:" 1 = A(−1 + 1) + B(−1 − 1); 1 = −2B, so B = −½; ∫ (½/(x − 1) − ½/(x + 1)) dx = ½ln|x − 1| − ½ln|x + 1| + C.
> Find the integral of one over x squared minus one. Start by factoring the bottom: x minus one, times x plus one. [pause]
> Whenever the denominator is a product of factors, we can rewrite the fraction as some number A over the first factor, plus some number B over the second factor, and so on, one piece for each factor. [pause]
> A and B are numbers we don't know yet. To find them, multiply both sides by the whole denominator, x minus one times x plus one. [pause]
> On the left, only the one is left. On the right, the x minus one cancels from the A piece, and the x plus one cancels from the B piece. So one equals A times x plus one, plus B times x minus one. [pause]
> That's a little equation to solve for A and B. It has to be true for every x, so we get to pick the x values. Choose them so that one term or the other cancels out. [pause]
> Let x equal one. We're choosing x to be one; we didn't solve for it. Then x minus one is zero, so the B term drops out: one equals A times two. [pause]
> So A is one half. [pause]
> Now let x equal negative one. This time x plus one is zero, so the A term drops out: one equals B times negative two. [pause]
> So B is negative one half. [pause]
> Put A and B back into the pieces. Each one integrates to a natural log: one half ln of absolute x minus one, minus one half ln of absolute x plus one, plus C. [long pause]

## Using the method
**On screen:** The problem: "Find ∫ (x + 7)/(x² − x − 6) dx." The split rule stays in the corner. Board: x² − x − 6 = (x − 3)(x + 2); (x + 7)/((x − 3)(x + 2)) = A/(x − 3) + B/(x + 2); x + 7 = A(x + 2) + B(x − 3); "Let x = 3:" 10 = 5A, so A = 2; "Let x = −2:" 5 = −5B, so B = −1; ∫ (2/(x − 3) − 1/(x + 2)) dx = 2ln|x − 3| − ln|x + 2| + C.
> Find the integral of x plus seven, over x squared minus x minus six. [try it]
> Factor the bottom: x minus three, times x plus two. [pause]
> Write A over the first factor plus B over the second factor. [pause]
> Multiply both sides by the denominator: x plus seven equals A times x plus two, plus B times x minus three. [pause]
> Let x equal three, so the B term drops out: ten equals five A, and A is two. [pause]
> Let x equal negative two, so the A term drops out: five equals negative five B, and B is negative one. [pause]
> Integrate the pieces: two ln of absolute x minus three, minus ln of absolute x plus two, plus C. [long pause]

## Close
**On screen:** "Factor the denominator." "Write A/(first factor) + B/(second factor) + ⋯" "Multiply through. Let x be each root to find A and B." "Each piece: A ln|linear|." "Top degree too big? Divide first."
> Factor the bottom and write A over the first factor plus B over the second. Multiply through, then let x be each root, so one term drops out at a time. Integrate each piece to a log. If the top's degree is too big, divide first. [long pause]

# Worked examples

## Example 1: Undo the addition
**On screen:** "Find ∫ (5x + 1)/((x − 1)(x + 2)) dx." Board: (5x + 1)/((x − 1)(x + 2)) = A/(x − 1) + B/(x + 2); 5x + 1 = A(x + 2) + B(x − 1); "Let x = 1:" 6 = 3A, so A = 2; "Let x = −2:" −9 = −3B, so B = 3; ∫ (2/(x − 1) + 3/(x + 2)) dx = 2ln|x − 1| + 3ln|x + 2| + C.
> Find the integral of five x plus one, over x minus one times x plus two. [pause]
> Write A over x minus one plus B over x plus two, and multiply through: five x plus one equals A times x plus two, plus B times x minus one. [pause]
> Let x equal one: six equals three A, so A is two. Let x equal negative two: negative nine equals negative three B, so B is three.
> These are the fractions from the opening. Integrate: two ln of absolute x minus one, plus three ln of absolute x plus two, plus C. [long pause]

## Example 2: A definite integral
**On screen:** "Evaluate ∫_2^3 1/(x(x − 1)) dx." Board: 1/(x(x − 1)) = A/x + B/(x − 1); 1 = A(x − 1) + Bx; "Let x = 0:" 1 = −A, so A = −1; "Let x = 1:" 1 = B, so B = 1; ∫_2^3 (−1/x + 1/(x − 1)) dx = [ln|x − 1| − ln|x|]_2^3; = (ln 2 − ln 3) − (ln 1 − ln 2) = 2ln 2 − ln 3 = ln(4/3).
> Evaluate the integral from two to three of one over x times x minus one. [pause]
> Write it as A over x plus B over x minus one, and multiply through: one equals A times x minus one, plus B times x. [pause]
> Let x equal zero: one equals negative A, so A is negative one. Let x equal one: one equals B, so B is one.
> An antiderivative is ln of absolute x minus one, minus ln of absolute x. [pause]
> At three: ln two minus ln three. At two: ln one minus ln two, which is negative ln two. Subtract: two ln two minus ln three, which is ln of four thirds. [long pause]
