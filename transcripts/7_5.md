# 7.5 Approximating Solutions Using Euler's Method

## Walking along tangent lines
**On screen:** The slope field for dy/dx = x + y, the true solution through (0, 1) drawn faintly. From (0, 1), a short tangent segment of slope 1 runs to x = 0.5, landing at (0.5, 1.5). From there a new segment of slope 2 runs to (1, 2.5). The true curve climbs above both steps to about (1, 3.44). A note: "BC only".
> When we can't solve a differential equation, we can still approximate a solution. This topic is for BC. [pause]
> Start at the known point, zero, one. The equation gives the slope there, one. Walk along that tangent line for a short step, to x equals point five. [pause]
> At the new point, get a new slope from the equation and walk again. Each step is a tangent-line approximation. That's Euler's method. [long pause]

## Title
**On screen:** (No narration: the card shows with the intro music.) Title card: "Topic 7.5 · Approximating solutions using Euler's method." Unit 7 · Differential Equations.

## The method
**On screen:** "Step size h. From (xₙ, yₙ): slope mₙ = dy/dx at (xₙ, yₙ); yₙ₊₁ = yₙ + h·mₙ; xₙ₊₁ = xₙ + h." Then a table with columns x, y, slope, Δy = h·slope, filling in for dy/dx = x + y, y(0) = 1, h = 0.5: row 1: 0, 1, 1, 0.5; row 2: 0.5, 1.5, 2, 1; row 3: 1, 2.5. Result: "y(1) ≈ 2.5".
> Choose a step size h. At each point, find the slope from the differential equation. [pause]
> The change in y is h times the slope. Add it to get the next y, and add h to get the next x. [pause]
> A table keeps it organized. Starting at zero, one, the slope is zero plus one, one. Times point five is point five, so the next point is point five, one point five. [pause]
> There the slope is point five plus one point five, two. Times point five is one, so the next point is one, two point five. So y of one is about two point five. [long pause]

## Over or under?
**On screen:** "d²y/dx² = 1 + dy/dx = 1 + x + y > 0 for these points: concave up." The picture again: tangent steps lie below a concave-up curve. "Concave up: Euler underestimates. Concave down: Euler overestimates." Actual value: y(1) = 2e − 2 ≈ 3.437.
> Is that an overestimate or an underestimate? Look at the concavity. [pause]
> The second derivative is one plus d y d x, which is one plus x plus y. That's positive here, so the solution is concave up. [pause]
> A concave-up curve lies above its tangent lines, so each Euler step lands too low. It's an underestimate. In fact the exact value is about three point four four. [long pause]

## Smaller steps
**On screen:** The problem: "dy/dx = y − x, y(0) = 2. Use Euler's method with two steps of size 0.25 to approximate y(0.5)." Table: (0, 2): slope 2, Δy = 0.5; (0.25, 2.5): slope 2.25, Δy = 0.5625; (0.5, 3.0625). Board: y(0.5) ≈ 3.0625.
> d y d x equals y minus x, with y of zero equal to two. Use Euler's method with two steps of size point two five to approximate y of point five. [try it]
> At zero, two, the slope is two minus zero, two. Times point two five is point five. The next point is point two five, two point five. [pause]
> There, the slope is two point five minus point two five, which is two point two five. Times point two five is point five six two five.
> Add it on: y of point five is about three point zero six two five. [long pause]

## Close
**On screen:** "yₙ₊₁ = yₙ + h · (dy/dx at (xₙ, yₙ))." "Use a table: x, y, slope, Δy." "Concave up: underestimate. Concave down: overestimate."
> Euler's method walks along tangent lines: new y equals old y plus step size times slope. Keep a table, and use concavity to decide over or under. [long pause]

# Worked examples

## Example 1: Two steps
**On screen:** "dy/dx = 2x, y(1) = 3. Use Euler's method with two steps of size 0.5 to approximate y(2). Is it an overestimate or an underestimate?" Table: (1, 3): slope 2, Δy = 1; (1.5, 4): slope 3, Δy = 1.5; (2, 5.5). Board: y(2) ≈ 5.5; d²y/dx² = 2 > 0, concave up: underestimate.
> d y d x equals two x, with y of one equal to three. Use two Euler steps of size point five to approximate y of two, and decide over or under. [pause]
> At one, three, the slope is two. Times point five is one, so the next point is one point five, four. [pause]
> There the slope is three. Times point five is one point five, so y of two is about five point five.
> The second derivative is two, positive: concave up. So five point five is an underestimate. [long pause]
